# HP Tracker

A free combat tracker for game masters running fifth edition (5e) games: hit points,
turn order, conditions, concentration, death saves, encounter difficulty, and player
screens on your players' phones.

**Website and download: https://imboro.github.io/hp-tracker/**

| | |
|---|---|
| **Windows** 10 or 11 | [HP-Tracker-Windows.zip](https://github.com/imboro/hp-tracker/releases/latest/download/HP-Tracker-Windows.zip) |
| **Mac** with Apple Silicon | [HP-Tracker-Mac.zip](https://github.com/imboro/hp-tracker/releases/latest/download/HP-Tracker-Mac.zip) |

All versions are in [Releases](https://github.com/imboro/hp-tracker/releases).
